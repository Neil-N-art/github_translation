# GitHub 中文翻译插件

这是 Chrome / Edge Manifest V3 插件的阶段 1 原型。手动翻译 github.com 当前页面，并可恢复原文。使用 DeepSeek 或 OpenAI 兼容的 Chat Completions API。

## 安装与使用

1. 下载本分支代码并解压，或克隆仓库。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。打开开发者模式，选择“加载已解压的扩展程序”，选择包含 `manifest.json` 的目录。
3. 点击插件图标，打开“翻译服务设置”，选择供应商并填写 HTTPS API 地址、模型和 API Key，保存时允许访问该服务。
4. 刷新 GitHub 页面，点击“翻译当前页面”，保持弹窗打开查看结果。点击“恢复原文”还原。每次最多处理 200 个文本片段；再次点击可处理下一批。

API Key 保存在本机扩展存储中，不要将密钥放进 Git 或共享截图。网页文本会发送给选定的服务商，可能产生费用。仅使用可信的 API 地址。不同标签页的翻译状态相互独立；刷新页面也可恢复原文。

## 当前边界

这是待验收的原型：不自动监听新增内容、不缓存、不测试连接，也不计算费用。API 兼容性、GitHub 页面变化与译文对命令和标识符的保护仍需真实页面测试。代码块、行内代码和输入框不会翻译；普通文本中出现的代码或命令无法保证完全识别。长文本超过 4000 字符的片段会跳过。暂不覆盖图片、字幕和浏览器内部页面。
