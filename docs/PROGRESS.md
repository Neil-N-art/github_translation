# 开发记录

## 阶段 1：可用原型（待验收）

- 本分支实现：Manifest V3 插件、手动翻译可见文本、独立供应商配置、恢复原文、代码区域排除及简单占位符保护。
- 自动测试：`node --test tests/*.test.js`；具体结果以提交时报告为准。
- 未验证：Chrome 和 Edge 实机加载、真实 DeepSeek/OpenAI 请求、GitHub README 的中英文转换及链接交互。需用户提供自己的密钥并在浏览器验收；不得提交密钥。
- 已知限制：按文本节点翻译可能割裂句子；占位符仅保护常见 URL、路径和部分标识符，无法保证所有命令和变量名。页面每次最多处理 200 段、每段不超过 4000 字符。翻译期间刷新可恢复页面；弹窗关闭会丢失当前进度显示。

## 下一项及验收

1. 在 Chrome / Edge 使用真实英文 README 和自己的 API Key 测试，确认翻译、代码不变、链接可点击、恢复原文及服务错误提示；记录问题并修复。
2. 加入针对动态内容、缓存、供应商切换、重试、设置限额和状态的阶段 2 工作。缓存键应包含原文、目标语言、供应商、模型及接口身份；禁止静默切换服务商。
3. 阶段 3：长页面分批和性能、测试及扩展网站权限。实机打包交付。
4. 独立验证云端任务的到期触发、额度不足与恢复行为；不能假设自动恢复。

每项开发应在独立分支进行，记录提交、测试、未解决问题和后续验收条件；合并由用户决定。
